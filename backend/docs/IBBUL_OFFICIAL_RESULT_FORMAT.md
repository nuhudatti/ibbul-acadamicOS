## Upload format (CSV / Excel) — LONG format (one row per student-course)

Use **one row per result**: each row must have **student id**, **course code**, and **score**.

### Accepted column names (case-insensitive; spaces and dots become underscores)

**Example header row:** `matric_number,course_code,score` or `MATRIC.NO,course_code,score` or `Matric No,Course Code,Score`

**Example data row:** `U22/FNS/CSC/0001,CSC301,75` or `U10/FNS/CSC/0004,CSC101,62`

- **Student ID:** Format `U{year}/{faculty}/{dept}/{number}`. All years supported (e.g. U10, U12, U22, U23). Faculty/dept: 2–4 letters; number: 1–5 digits. Case-insensitive (stored uppercase).
- **Existing students and courses only:** The system does **not** create new students or new courses from the upload. Only **existing** students (in user management) and **existing** courses (in the course catalogue) can have results uploaded. Add students and courses first, then upload. Rows with an unknown student ID or course code will fail and appear in the import report.
- **Score:** Must be 0–100 (0 is valid).
- **Excel university format (one column per course):** Header row has S/N, MATRIC.NO, NAME, then **one column per course** (e.g. CSC 401, CSC 403, MTH 309, GST 301), then **summary columns (required for full official format):** RCU, ECU, CP, GPA, TRCU, TECU, TCP, CGPA, OUTSTANDING COURSES, REMARKS, STATUS, FINAL STATUS. Each course cell may contain **"63 B"** (score + space + grade), **"B"** only, **"63"** only, or be empty. The system parses this format first; only data from your uploaded file is used. Only **registered students** and **existing courses** are uploaded; others appear in the import report.
- **Excel wide format (legacy):** If the university format is not detected, the system tries the wide layout: S/N, MATRIC.NO, NAME, then course codes every two columns with score in the first column of each pair. Again, only the file you upload is read (from bytes); no path or cached file is used.
- **Messy sheet (multiple header rows, course codes with spaces):** Run the cleanup script from project root: `python scripts/clean_result_sheet.py your_file.xls -o cleaned.csv --session "2023/2024" --semester SECOND`. It outputs CSV with columns `matric_number, course_code, score, grade` (and optional session/semester). Upload the generated CSV; only rows for existing students and courses will succeed; the rest appear in the import report.
- Rows missing student_id, course_code, or a numeric score are skipped.
- If you see "No rows with student_id, course_code, and score found", check that: (1) the first row is a header with these column names (or aliases above), (2) data rows have no empty cells for matric, course code, and score.
